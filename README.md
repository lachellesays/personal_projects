# Trial tools

Apps for running Level Up Dog Sports UKI agility trials.

| Folder | What it is | Where it runs |
|---|---|---|
| `FormattingTools/trial_formatter/` | Entry formatter: JotForm entries → 3-tab trial workbook, with scratches and typo fixes | Railway |
| `CheckinApp/` | Trial-day check-in, running order, gate steward, admin, results | Railway |
| `FormattingTools/generate_results.py`, `generate_run_order.py` | Scripts that build the results and run order PDFs | Your Mac |
| `TrialManager/mockups/` | Design previews for the planned all-in-one app (formatter, check-in, online entries) | — |

Each app folder has its own README with setup steps.

Trial data files (entries, workbooks, results) are kept in `~/Documents/Trial Archive`, not in this repo,
because they contain exhibitors' personal information.
